# QoSense Glossary

Spell out each abbreviation at first use in user-facing documentation. Keep explanations short and useful.

| Short form | Full form | Simple meaning in QoSense |
|---|---|---|
| QoS | Quality of Service | Rules that decide how network traffic is treated. |
| QoE | Quality of Experience | How good the user's application/network experience feels. |
| AI | Artificial Intelligence | Computer systems performing tasks that normally require human-like reasoning. |
| ML | Machine Learning | Methods that learn patterns from data. |
| GBDT | Gradient-Boosted Decision Trees | A model that combines decision trees in sequence to improve predictions. |
| LightGBM | Light Gradient Boosting Machine | A gradient-boosted decision-tree framework used for the two QoSense models. |
| eBPF | Extended Berkeley Packet Filter | A Linux technology for running controlled programs to observe/manage kernel events. |
| RTT | Round-Trip Time | Time for a probe to travel to a destination and its response to return. |
| EWMA | Exponentially Weighted Moving Average | A smoothing calculation that gives more weight to recent measurements. |
| IFB | Intermediate Functional Block | A virtual Linux interface used to redirect incoming packets for shaping. |
| HTB | Hierarchical Token Bucket | A Linux traffic-control queuing discipline that shapes rates using classes. |
| FQ-CoDel | Fair Queuing Controlled Delay | A queueing method that shares flows fairly and helps control delay. |
| CAKE | Common Applications Kept Enhanced | A Linux traffic-shaping/queue-management system; evaluate as an alternative benchmark. |
| DSCP | Differentiated Services Code Point | A field in the IP header used to signal a traffic treatment class. |
| DPI | Deep Packet Inspection | Inspection of packet contents beyond basic network headers. |
| VPN | Virtual Private Network | A protected network connection, often encrypting traffic in a tunnel. |
| API | Application Programming Interface | A defined way for software components to communicate. |
| CPU | Central Processing Unit | The main processor that runs program instructions. |
| VM | Virtual Machine | A software-based computer running on a physical host. |
| WAN | Wide Area Network | The network connection between the home gateway and the wider Internet/service provider. |
| LAN | Local Area Network | The network connecting devices inside the home. |
| UDP | User Datagram Protocol | A transport protocol that sends datagrams without TCP-style connection delivery guarantees. |
| TCP | Transmission Control Protocol | A transport protocol that provides ordered, reliable byte-stream delivery. |
| JSON | JavaScript Object Notation | A common text format for structured API data. |
| WebSocket | WebSocket protocol | A long-lived two-way connection for streaming updates between browser and server. |
| PR-AUC | Precision-Recall Area Under the Curve | A summary of precision/recall trade-offs, often useful for rare positive events. |
| F1 | F1 score | The harmonic mean of precision and recall. |
| IFB | Intermediate Functional Block | Virtual interface used in Linux ingress shaping patterns. |

Note: Confirm the official expansion of every technology name before using it in external submissions. Some names are product/project names rather than conventional abbreviations. Do not invent expansions.
